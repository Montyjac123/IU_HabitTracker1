# Habit Tracking App

## What is it?

A command-line habit tracking application built with Python.

Users can:
- Add daily or weekly habits
- Mark habits as completed
- Track completion streaks
- Filter habits by periodicity
- Save and load progress using JSON storage

---

## Installation

```shell
pip install -r requirements.txt
```

---

## Usage

Run the application:

```shell
python main.py
```

Follow the instructions shown in the terminal.

---

## Features

- Habit creation
- Habit completion tracking
- Streak calculation
- Persistent storage
- Filtering system
- Error handling
